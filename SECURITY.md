# Security Policy

## Supported versions

Security fixes are primarily expected for the latest published release.

## Reporting a security issue

Please do not open public issues for sensitive security problems first.

Use one of the following contact methods:

- WeChat: `BAIY_13`
- Website: [dn.zcyai.cn](https://dn.zcyai.cn)

## Project security boundaries

This repository is intended for visible, authorized, local-device monitoring use cases only.

The project should not be extended to include:

- Hidden background surveillance
- Privilege escalation
- Unauthorized persistence
- Keylogging of exact typed content
- Bypass of user consent or device ownership

Changes that violate these boundaries should not be accepted.
