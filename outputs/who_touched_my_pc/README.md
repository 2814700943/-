## 功能

- 模式一：默认立即布防，启动后约 1.5 秒进入布防状态，下一次鼠标或键盘活动会保存摄像头照片；如果摄像头不可用，则自动保存屏幕截图，然后锁屏。也可以关闭“立即布防”，改为达到闲置阈值后触发。
- 模式二：主动开启后，定期截图、尝试摄像头拍照，并记录键鼠活动发生时间和当前窗口标题。
- 输出方式：保存到本地目录，或通过 SMTP 实时发送附件。
- 图片格式：`jpg` 或 `png`，文件名按时间戳生成。
- 新版界面：左侧导航、模式卡片、最近记录表、设置中心、邮箱设置和帮助文档。
- 附加工具：测试截图、测试摄像头、测试邮件、打开目录、导出日志 zip、按容量清理旧文件。

## 重要说明

此版本是透明运行的本机工具，不做隐藏运行、开机自启动或隐蔽采集。键盘记录只保存“发生了键盘活动”，不会保存具体按键内容。

浏览器 URL、文件打开明细、应用进程名等深度行为审计没有在原型里强行做，因为它们需要更高权限、浏览器扩展或专门的 Windows 审计策略。当前版本记录的是活动窗口标题和输入事件。

## 运行

在 PowerShell 中进入此目录：

```powershell
.\run.ps1
```

如果系统没有安装 Python：

1. 安装 Python 3.11 或更新版本。
2. 重新打开 PowerShell。
3. 再运行 `.\run.ps1`。

## 邮件配置

在界面的“邮件”页填写：

- SMTP 主机，例如 `smtp.qq.com`、`smtp.gmail.com`
- SMTP 端口，通常是 `587`
- SMTP 用户名
- SMTP 密码或邮箱授权码
- 收件邮箱

然后在“保存”页把输出方式改为 `email`，并勾选“触发后实时发送附件”。

### QQ 邮箱示例

1. 登录 QQ 邮箱网页版。
2. 进入 `设置` -> `账号`。
3. 开启 `POP3/SMTP服务` 或 `IMAP/SMTP服务`。
4. 按页面提示获取“授权码”。注意不要填写 QQ 登录密码，软件里要填写这个授权码。
5. 在软件“邮箱设置”里填写：

```text
SMTP 主机：smtp.qq.com
SMTP 端口：587
SMTP 用户名：你的完整 QQ 邮箱，例如 123456@qq.com
SMTP 密码/授权码：QQ 邮箱生成的授权码
收件邮箱：接收照片和截图的邮箱，可填同一个 QQ 邮箱
```

保存后点击 `发送测试邮件`。如果能收到测试邮件，说明配置成功。

## 本地文件

- 截图/照片默认保存到 `captures`
- 运行日志保存到 `logs`
- 配置保存在 `config.json`

## 生成 exe

安装 Python 后运行：

```powershell
.\build_exe.ps1
```

生成位置：

```text
dist\谁动了我的电脑.exe
```

新版默认生成单文件 exe，可以单独复制使用。配置、日志和截图会保存在 exe 同级目录旁边。
